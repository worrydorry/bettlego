# bettlego
BEETLE + BATTLE vibe coding game for children

곤충을 좋아하는 초등 저학년의 학습을 돕기 위해 바이브코딩으로 만든 **곤충채집 탐험일기** 게임입니다.<br>
숲을 탐험하며 곤충의 흔적을 찾고, 덧셈·뺄셈(받아올림·받아내림)·영어·한자 문제를 풀어 곤충과 겨루고, 잡은 곤충을 도감에 모읍니다.

- 게임 하기: https://worrydorry.github.io/bettlego/
- 권장 환경: Windows·Android의 Chrome·Edge·삼성 인터넷(가로 화면). 아이폰·아이패드 Safari는 지원 대상이 아닙니다.
- 만든 사람: worrydorry(inho.yeo.rok@gmail.com) · 그래픽: Microsoft Copilot(AI) 생성 · 코드: Claude(AI) 생성 · 비영리
- 사용한 글꼴·사진의 출처와 라이선스는 게임 메인 화면 아래 [라이선스]에서 볼 수 있습니다.

## 1. 처음 시작하기
1. **이름 정하기**: 처음 들어오면 탐험가(아이)의 이름을 적습니다. 한글·영어·숫자로 최대 8글자입니다.
2. **숫자 써 보기(30번)**: 장수풍뎅이가 종이 위를 기어가고, 지나간 자리에 숫자가 나타납니다. 오른쪽 종이에 그 숫자를 따라 쓰고 [다 썼어요]를 누릅니다.
   - 0부터 9까지 각 3번, 모두 30번 씁니다. 아이의 글씨 모양을 미리 익혀 두어 전투에서 손글씨를 더 정확하게 알아보기 위한 과정입니다.
   - 쓰는 동안 장수풍뎅이가 말풍선으로 게임 방법·도감·문제 유형·옵션을 설명해 줍니다(문제 유형을 설명할 때는 예시 화면도 보여 줍니다).
3. 다 쓰면 그 장수풍뎅이가 **첫 곤충**으로 도감에 등록되고, 함께 탐험할 **출전 곤충**(노란 별)이 됩니다.
4. 휴대폰·태블릿에서는 화면을 한 번 누르면 전체 화면으로 바뀌고 가로로 고정됩니다(지원하는 브라우저만). 세로로 들고 있으면 [눌러서 가로 화면으로 하기] 버튼이 나옵니다.

## 2. 게임 방법

### 메인 화면
| 버튼 | 하는 일 |
|---|---|
| 새로하기 | 새 모험을 시작합니다. 진행 중인 모험이 있으면 확인 뒤 그 모험을 포기하고 새로 시작합니다. |
| 이어하기 | 저장된 모험을 이어서 합니다(진행 중인 모험이 있을 때만). |
| 도감 | 잡은 곤충을 모아 둔 도감을 봅니다([6. 도감](#6-도감)). |
| 옵션 | 이름·문제 과목·난도 등을 바꿉니다([4. 일반 옵션](#4-일반-옵션)). |
| 오른쪽 아래 도토리·솔방울 | 고급옵션(보호자용) 입구입니다([5. 고급옵션](#5-고급옵션보호자용)). |

### 탐험(모험)
- 모험은 **출발 전(0일) + 1~15일**입니다. 출전 곤충은 모험마다 처음 능력치(Lv.1)에서 시작합니다.
- **발자국**을 누르면 다음 장소로 한 걸음 나아갑니다(이동할 때마다 자동 저장).
- **갈림길**: 길이 두 갈래로 나뉘면 왼쪽·오른쪽 발자국 중 하나를 고릅니다.
- 장소(배경)는 정글·침엽수림·활엽수림·잡목림입니다.
- **흔적**: 장소마다 곤충의 흔적이 숨어 있을 수 있습니다. 흔적을 눌러 조사하면 야생 곤충이 나타납니다.
  1. 수액이 흐르는 참나무
  2. 부엽토 속 C자형 애벌레
  3. 흙 속 번데기 방
  4. 나뭇잎 뒤로 숨은 실루엣(그림자)
  5. 나무줄기의 보호색
- 흔적을 찾지 못한 채 발자국을 누르면 힌트가 나옵니다. [무시하기]로 그냥 지나가거나 [돌아가기]로 더 찾아볼 수 있습니다.

### 전투
- 전투는 **내 공격 → 적의 공격**을 번갈아 합니다. 화면 가운데 나무 판에 문제가 나옵니다([3. 문제](#3-문제)).
- **내 공격**: 제한시간 안에 문제를 맞히면 적에게 피해를 줍니다. 피해 = 내 공격력 − 적 방어력.
- **적의 공격(방어)**: 제한시간 안에 문제를 맞히면 막아 냅니다. 틀리거나 시간이 다 되면 내가 맞습니다.
- **피격 기회**: 정해진 횟수(기본 3번)만큼 맞으면 **패배**합니다. 마지막으로 맞을 때 가끔(10%) '최후의 저항'이 일어나 한 번 더 버틸 수 있습니다.
- **승리**: 적이 절뚝거리며 도망가기 시작합니다. 약 10초 안에 **[포획!]**을 누르면 채집, 누르지 않으면 놓아줍니다.
- 이기면(포획하든 놓아주든) **레벨 +1**, 공격력·방어력·최대 체력이 각각 +1~3 오르고 체력이 회복됩니다(고급옵션에서 회복 방식을 바꿀 수 있음).

### 캠프(5일·10일·15일)
- 캠프에 도착하면 채집통의 곤충이 **도감에 자동 등록**됩니다.
- 캠프에서는 그날 장소를 밤처럼 어둡게 한 화면에서 오브젝트를 눌러 고릅니다.
  - **돗자리** = 도감 보기(출전 곤충 바꾸기·이름 짓기 가능)
  - **이정표** = 다음 구간 도전
  - **텐트** = 탐험 종료 및 귀환(5·10일 캠프 — '성공'으로 끝남)
- **15일 캠프**에 도착하면 모험 완주입니다.

### 모험이 끝나는 경우
| 경우 | 결과 |
|---|---|
| 15일 완주 / 5·10일 캠프에서 귀환 | 성공. 채집한 곤충은 캠프에서 이미 등록됨 |
| 패배 | 모험이 끝나고 다시 이어할 수 없음. 마지막 캠프 이후 채집통에 있던 곤충은 등록되지 않음 |
| [탐험 중단] → [일시 중단] | 지금 상태를 저장하고 메인으로(나중에 [이어하기]) |
| [탐험 중단] → [완전 중단] | 채집통의 곤충은 등록할 수 없다는 안내 뒤 [모험 중단하기]로 끝냄 |

- 출전 곤충의 **모험 최대 기록**(공격력·방어력·체력)은 도감 카드에 남습니다.

## 3. 문제
문제 과목은 [옵션]에서 고릅니다. 여러 과목을 고르면 문제마다 같은 비율로 섞여 나옵니다.

### 수학 — 세로셈 덧셈·뺄셈
- 받아올림·받아내림이 있는 덧셈·뺄셈이 교과서처럼 **세로셈**으로 나옵니다. 자릿수는 2·3·4자리 중에서 고릅니다(기본 2자리).
- 칸을 누르면 오른쪽에 필기 종이가 열립니다. 숫자를 손으로 쓰고 버튼을 누릅니다.
  - [다 썼어요] = 쓴 숫자를 인식 · [빈칸이에요] = 이 칸은 비움 · [다시 쓰기] = 지우고 다시
  - [옵션]에서 '자동 인식'을 켜면 펜을 떼고 1초 멈출 때 바로 인식합니다.
- 받아올림·받아내림 숫자를 적는 작은 칸도 있습니다.
- 같은 칸을 두 번 틀리면 그 문제는 실패입니다. 제한시간이 끝나면 쓰던 글씨까지 제출해 보고, 정답이 아니면 실패입니다. 실패하면 정답 풀이를 보여 준 뒤 [확인]으로 넘어갑니다.

### 영어 — 객관식
- 영어 낱말을 보고 뜻을, 또는 뜻을 보고 영어 낱말을 3개 보기 중에서 고릅니다(두 방향 반반).
- 한 번 틀리면 실패입니다. 실패하면 정답을 보여 주고 [확인]으로 넘어갑니다.

### 영어 — 주관식
- 한글 뜻을 보고, 세 줄 영어 공책의 밑줄에 알파벳을 한 글자씩 채웁니다.
- 아래 알파벳 버튼 3개 중 하나를 누르면 지금 칸(굵은 밑줄)에 들어갑니다. 보기에는 아이가 헷갈리기 쉬운 글자(b/d, q/p, y/i, a/e, r/l, s/c 등)가 섞여 나옵니다(i와 l은 함께 나오지 않음).
- [지우기] = 한 글자 지우기 · [전체지우기] = 모두 지우기 · **[제출]** = 다 채운 뒤 눌러서 채점
- 제한시간은 칸 하나를 채울 때마다 다시 잽니다. [제출]을 누르지 않고 시간이 다 되면 그 상태로 채점합니다.
- 한 번 틀리면 처음부터 한 번 더, 두 번째도 틀리면 실패입니다. 실패하면 정답 철자를 보여 줍니다.

### 영어 — 혼합
- 문제마다 객관식과 주관식이 같은 비율로 무작위로 나옵니다.

### 한자 — 객관식
- 한자를 보고 뜻과 소리(예: 하늘 천)를, 또는 뜻과 소리를 보고 한자를 3개 보기 중에서 고릅니다.
- 한자 주관식·혼합은 아직 준비 중입니다.

### 단어장
- 영어: 기본 단어장 20낱말, 한자: 기본 한자 150자가 들어 있습니다.
- 고급옵션에서 단어장을 올리거나 고칠 수 있습니다. 한 줄에 한 쌍씩 `apple:사과`(영어), `하늘천:天`(한자)처럼 씁니다.
- 영어는 뜻이 서로 다른 낱말이 3개 이상, 한자는 같은 종류의 낱말이 3개 이상 있어야 그 과목을 고를 수 있습니다.

## 4. 일반 옵션
메인 화면 [옵션]에서 바꿉니다(고급옵션 화면의 [일반옵션] 탭과 같은 내용).

| 항목 | 설명 |
|---|---|
| 이름 바꾸기 | 탐험가(아이) 이름. 한글·영어·숫자 최대 8글자 |
| 자동 인식 | 켜면 펜을 떼고 1초 멈출 때 숫자를 바로 인식(기본 끔) |
| 문제 과목 | 수학·영어·한자 체크 칸. 여러 개면 같은 비율로 섞임. 단어장 낱말이 모자란 과목은 고를 수 없음 |
| 난도 | 수학 = 2·3·4자리 / 영어 = 객관식·주관식·혼합 / 한자 = 객관식(주관식·혼합은 준비 중) |
| 데이터 내려받기 / 올리기 | 게임 데이터를 파일로 저장하거나, 저장한 파일로 되돌림([7. 데이터](#7-데이터-저장과-옮기기)) |

- 아래 [저장하고 메인으로]를 눌러야 저장됩니다. [저장하지 않고 메인으로]는 바꾼 내용을 버립니다.
- 난도·문제 과목은 **다음 모험부터** 적용됩니다.

## 5. 고급옵션(보호자용)
- 들어가기: 메인 화면 **오른쪽 아래의 도토리나 솔방울**을 누르고 비밀번호 **0000**을 입력합니다.
- 화면 위 [고급옵션]·[일반옵션] 탭으로 두 화면을 오갑니다. [저장하고 메인으로]·[저장하지 않고 메인으로]는 두 탭을 한꺼번에 처리합니다.
- 설정은 **다음 모험부터** 적용됩니다(진행 중인 모험에는 반영되지 않음).

### 게임 설정
| 항목 | 범위 | 기본값 | 설명 |
|---|---|---|---|
| 칸당 제한시간 | 3~30초 | 10초 | 세로셈 한 칸을 쓰는 시간. 영어·한자 객관식은 문제당, 영어 주관식은 한 글자당 |
| 피격 기회 | 2~5회 | 3회 | 이만큼 맞으면 패배 |
| 레벨업 시 체력 회복 | 켬/끔 | 켬 | 끄면 레벨업 때 회복하지 않고 캠프에 도착할 때 회복(캠프 전까지 맞은 횟수가 쌓임) |
| 적의 강함 | 1~4 | 3 | 적을 도망가게 하려면 내 공격을 몇 번 맞혀야 하는지 |
| 흔적 등장 확률 | 50~100% | 75% | 캠프가 아닌 장소에 흔적이 생길 확률 |
| 곤충 크기 출현 비율 | 소·중·대 숫자 | 30·40·30 | 비율대로 나옴(합이 100이 아니어도 비례 배분, 실제 % 표시) |
| 곤충 종류별 출현 비율 | 종마다 숫자 | 모두 같음 | 6종의 나오는 비율 |

### 단어장
- [단어장 업로드] = 텍스트 파일(.txt)로 단어장 올리기(전체 바꾸기 또는 합치기, 영어/한자 고르기)
- [단어장 편집] = 게임 안에서 직접 고치기 · [단어장 내려받기] = 지금 단어장을 파일로 저장
- 화면 맨 위에 지금 쓸 수 있는 낱말 수가 나옵니다.

### 기록·테스트 도구
| 버튼 | 하는 일 |
|---|---|
| 숫자 다시 써 보기 | 숫자 써 보기(30번)를 다시 해서 글씨 인식을 새로 맞춤(곤충은 주지 않음) |
| 누적 필기 지우기 | 전투 중 쌓인 정답 필기(인식 보정용)를 지움 |
| 탐험 진행 지우기 | 진행 중인 모험을 지움 |
| 도감·기록 초기화 | 도감을 첫 곤충 1마리로 되돌리고 모험을 지움 |
| 빠른 전투 테스트 | 탐험 없이 전투만 해 봄(능력치·적 종류·배경 선택) |
| 전투 개발자 정보 / 흔적 위치 표시 | 테스트용 표시 |

## 6. 도감

### 등장하는 곤충(6종)
| 곤충 | 학명 | 색 |
|---|---|---|
| 장수풍뎅이 | *Trypoxylus dichotomus* | 갈색·검은색 |
| 케이론청동장수풍뎅이 | *Chalcosoma chiron* | 청동빛·검은색 |
| 헤라클레스왕장수풍뎅이 | *Dynastes hercules* | 노란색·녹회색 |
| 기데온장수풍뎅이 | *Xylotrupes gideon* | 적갈색·검은색 |
| 오각뿔장수풍뎅이 | *Eupatorus gracilicornis* | 적갈색·연한갈색 |
| 켄타우로스장수풍뎅이 | *Augosoma centaurus* | 적갈색·흑갈색 |

- 같은 종이라도 뿔 길이·몸통 길이(소·중·대)와 색이 개체마다 다르고, 실제 mm 크기가 정해집니다.

### 책꽂이와 도감 책
- 메인 [도감](또는 캠프의 돗자리)을 누르면 **책꽂이**가 나오고, 곤충 종류마다 책이 한 권씩 꽂혀 있습니다(책등에 이름과 마릿수).
- 책을 누르면 펼쳐지고, 한 쪽에 3마리씩 카드가 들어 있습니다. ◀ ▶로 쪽을 넘기고, 양옆 큰 ◀ ▶로 다른 곤충 도감으로 갑니다. [책 덮기]로 닫습니다.

### 곤충 카드
- **그림**: 그 개체의 실제 모습(큰 개체는 크게, 작은 개체는 작게)
- **이름**: 이름을 누르면 이름을 짓거나 바꿀 수 있습니다(한글·영어·숫자 최대 8글자).
- **하트**(왼쪽 위): 좋아하는 곤충 표시
- **별**(오른쪽 위): 노란 별 = 출전 곤충. 회색 별을 누르면 그 곤충이 출전 곤충이 됩니다(출전 곤충은 이름이 꼭 있어야 함). 캠프에서 바꾸면 이번 모험에 바로 적용됩니다.
- **모험 최대 기록**: 출전했을 때의 최고 공격력·방어력·체력
- **정보**: 색 · 전체 길이 mm (대형·중형·소형), 언제·어디서·어떤 흔적으로 발견했는지
- **NEW!**: 직전(또는 진행 중) 모험에서 새로 잡은 곤충. 다음 모험을 시작하면 사라집니다.
- 정렬: 출전 곤충(별) → 하트 → 나머지(최근 등록순)

### 진짜 곤충 도감
- 카드의 **곤충 그림을 누르면** 그 종의 진짜 곤충 도감이 열립니다: 사진, 분류(계·문·강·목·과·속·종), 사는 곳, 크기, 먹이, 한살이, 만나는 때, 특징, 아종.
- 사진을 누르면 크게 보고, 사진이나 [닫기]를 누르면 작게 돌아갑니다.

## 7. 데이터 저장과 옮기기
- 게임 데이터는 **이 브라우저 안에** 저장됩니다(인터넷 서버에 올라가지 않음). 브라우저 데이터를 지우거나, 다른 기기·다른 브라우저·다른 주소에서 열면 데이터가 보이지 않습니다.
- **[옵션] → [데이터 내려받기]**: 도감(이름·하트·출전 곤충 포함), 필기 인식 자료, 진행 중인 모험, 옵션(아이 이름 포함), 단어장, 모험 기록을 파일 하나(.json)로 저장합니다. 저장 창은 다운로드 폴더에서 열리고, 폴더와 파일 이름을 바꿀 수 있습니다.
- **[옵션] → [데이터 올리기]**: 저장한 파일을 고르면 내용(아이 이름·도감 수 등)을 확인한 뒤, 지금 데이터를 안전 백업 파일로 먼저 저장하고 파일 내용으로 바꿉니다. 바꾼 뒤 게임이 처음 화면부터 다시 시작합니다.
- 기기를 바꾸거나 새 주소로 옮길 때 이 두 버튼을 쓰세요.

### 팁
- **버튼이 있는 팝업에서 빈 곳을 누르면** [취소]·[돌아가기]·[닫기]·[확인] 중 하나를 누른 것과 같습니다(우선순위: 취소 → 돌아가기 → 닫기 → 확인, 입력 칸이 있는 팝업은 [확인]을 자동으로 누르지 않음).
- 화면을 세로로 돌리거나 다른 앱으로 가면 제한시간이 멈춥니다.
